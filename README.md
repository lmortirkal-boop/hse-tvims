# Колокол и порог — тренажер к пересдаче ТВиМС

Тренажер задач к пересдаче курса «Теория вероятностей и математическая статистика» (НИУ ВШЭ).
Открывается кнопкой в Telegram-боте или по ссылке https://lmortirkal-boop.github.io/hse-tvims/ .

В репозитории только собранный файл `index.html`. Исходники и сборка — у автора (`python build.py`).
Прогресс хранится в аккаунте Telegram каждого человека (CloudStorage бота) или в браузере.
